# Kachi 용어사전

| Korean | English | Description |
| --- | --- | --- |
| 사용자 | User | Kachi를 사용하는 회원. 관심 키워드를 등록하고 뉴스 요약 알림을 받을 수 있다. |
| 키워드 | Keyword | 사용자가 등록한 관심 주제. 뉴스 수집과 요약 대상 선정의 기준이 된다. |
| 뉴스 | News | 외부 뉴스 API 또는 RSS에서 수집한 기사 데이터. |
| 뉴스 Provider | News Provider | Google News RSS, Naver Search API, Finnhub Company News처럼 뉴스를 제공하는 외부 연동 대상. |
| 수집 실행 | Collection Run | scheduler 또는 internal API로 시작된 수집 작업 한 번의 실행 기록. |
| 활성 키워드 | Active Keyword | 사용자가 등록했고 `enabled=true`인 수집 대상 키워드. |
| 시장 데이터 | Market Data | 종목, 지수, 가격 등 뉴스 해석에 필요한 금융 시장 데이터. |
| 키워드 확장 | Keyword Expansion | 사용자의 키워드를 AI가 관련 검색어로 확장하는 작업. |
| 요약 | Summary | 수집된 뉴스 묶음을 AI가 사용자에게 읽기 쉬운 형태로 정리한 결과. |
| AI 실행 | AI Run | 키워드 확장 또는 뉴스 요약 작업 한 번의 실행 기록. |
| LLM Provider | LLM Provider | OpenAI 같은 텍스트 생성 모델 제공자. |
| 프롬프트 버전 | Prompt Version | AI 응답 재현성과 변경 추적을 위해 프롬프트 계약에 붙이는 버전. |
| 감성 | Sentiment | 뉴스 또는 요약 결과가 긍정, 중립, 부정 중 어디에 가까운지를 나타내는 값. |
| 알림 | Notification | 요약 결과를 Slack, Discord, Telegram 등 외부 채널로 발송하는 메시지. |
| 알림 채널 | Notification Channel | 사용자가 알림을 받을 외부 서비스 채널. |
| 발송 이력 | Notification History | 알림 요청, 발송 성공, 발송 실패, 재시도 결과에 대한 기록. |
| 이력 | History | 사용자별 뉴스, 요약, 알림 결과를 장기 보관한 기록. |
| Outbox | Outbox | 트랜잭션 안에서 생성한 발송 이벤트를 비동기로 안정적으로 처리하기 위한 저장소. |
| Dispatch | Dispatch | 접수된 알림을 worker가 실제 외부 채널로 발송하는 실행 단계. |
| Dispatch Message | Notification Dispatch Message | notification-service가 worker에 발행하는 발송 실행 메시지. |
| 멱등 마커 | Dedupe Marker | 같은 요청이나 dispatch 메시지가 중복 처리되지 않도록 Redis 등에 기록하는 단기 마커. |
| Idempotency Key | Idempotency Key | 외부 vendor 재호출 시 같은 발송으로 인식시키기 위해 재사용하는 키. |
| Claim | Claim | 여러 worker나 publisher 중 하나만 처리하도록 상태를 조건부로 선점하는 행위. |
| Stale Publishing | Stale Publishing | outbox가 `PUBLISHING` 상태로 오래 남아 publisher 중단으로 간주되는 상태. |
| RetryFailure | Retry Failure | 실패 코드, 실패 원천, 실패 분류, status code, retry-after를 담는 표준 실패 모델. |
| RetryPolicy | Retry Policy | 실패가 자동 재시도 대상인지, 한도에 도달했는지, 다음 backoff가 얼마인지 결정하는 정책. |
| RetryDecision | Retry Decision | retry 정책이 반환하는 `Retry` 또는 `GiveUp` 결정. |
| RETRY_WAIT | Retry Wait | 자동 재시도 가능한 발송 실패가 다음 Kafka retry/backoff를 기다리는 상태. |
| DEAD | Dead | 자동 재시도 한도에 도달했거나 재시도 불가능해 운영자 수동 처리만 남은 상태. |
| DLT | Dead Letter Topic | Kafka retry가 끝난 메시지나 runtime 처리 실패 메시지를 보관하는 topic. |
| Dispatch Attempt | Dispatch Attempt | worker가 sender 결과를 확정한 발송 시도 횟수. |
| Sender | Sender | Slack, Discord, Telegram 같은 채널별 외부 발송 adapter. |
